## Lombok Annotations

| Annotation | Main Purpose |
|------------|--------------|
| `@Getter` | Generate getters |
| `@Setter` | Generate setters |
| `@Data` | Generate common data methods |
| `@Value` | Create immutable data classes |
| `@NoArgsConstructor` | Generate no-argument constructor |
| `@AllArgsConstructor` | Generate constructor with all fields |
| `@RequiredArgsConstructor` | Generate constructor for required fields |
| `@ToString` | Generate `toString()` |
| `@EqualsAndHashCode` | Generate `equals()` and `hashCode()` |
| `@Builder` | Implement Builder pattern |
| `@SuperBuilder` | Implement Builder pattern with inheritance |
| `@NonNull` | Generate null validation |
| `@With` | Create modified copies of objects |
| `@Slf4j` | Create SLF4J logger |
| `@Log` | Create Java Util Logger |
| `@Log4j` | Create Log4j logger |
| `@Log4j2` | Create Log4j2 logger |
| `@Cleanup` | Automatically clean up resources |
| `@Synchronized` | Simplify synchronized methods |
| `@SneakyThrows` | Avoid explicit checked-exception handling |
| `@UtilityClass` | Create utility class with static members |
| `@Delegate` | Generate delegation methods |
| `@Accessors` | Customize getter/setter style |
| `@FieldDefaults` | Set default field modifiers |
| `@FieldNameConstants` | Generate field-name constants |
| `@Jacksonized` | Integrate Lombok builder with Jackson |
