## Procedural Programming

> **We need to follow steps and complete the action**

Eg: Lemonade 

1. Take lemons

2. Cut the lemons

3. Squeeze lemons

4. Add water

5. Add sugar

6. Mix it

7. Serve (Action is not completed until served)
---

## Object Oriented Programming

> **Each class has multiple entities and each entity has its own characteristics and behaviour.**

Eg: Lemonade

- Lemons
    - juice()

- Water
    - Amount

- Sugar
    - Amount

- Lemonade
    - addLemonJuice()
    - addSugar()
    - addWater()
    - mix()
---
